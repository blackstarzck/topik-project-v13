한글 단어 음절별 자모 색상 생성기

이 버전은 완성형 글자의 붙어 있는 픽셀을 억지로 나누지 않습니다. 각 음절을 초성·중성·종성 자모로 먼저 분해한 뒤 서로 독립적으로 그리기 때문에, ‘오·와·워·의’처럼 자음과 모음이 맞닿는 글자도 색이 섞이지 않습니다.
안정 분리형 렌더링 + 나눔고딕 기본

최근에 사용한 색

색상 칸을 먼저 누른 뒤 아래 색을 선택하면 바로 적용됩니다. 최근 색은 브라우저에 저장됩니다.

적용 대상: 전체 초성 기본색

음절별 색상

각 음절의 초성·중성·종성을 독립적으로 설정합니다. 이중모음은 전체가 하나의 중성 색으로 표시됩니다.

오류 원인과 수정: 이전 파일은 완성형 글자를 먼저 그린 뒤 연결된 픽셀 덩어리를 분류했습니다. 폰트에서 ㅇ과 ㅗ, 또는 초성과 이중모음이 맞닿으면 하나의 덩어리가 되어 오분류되었습니다. 이번 파일은 자모를 각각 별도의 그리기 명령으로 렌더링하므로 획이 가까워도 색상 정보가 합쳐지지 않습니다.
