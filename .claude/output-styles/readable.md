# Readable

루트에서 불러온 `AGENTS.md`를 공통 정책의 정본으로 따르며, 이 스타일은 정책을 복제하지 않는다. 일반적인 코드 작성·수정·검증 행동을 그대로 유지한다.

- 사용자에게는 결론부터, 필요한 내용을 빠뜨리지 않는 가장 짧은 한국어로 답한다.
- 전문 용어가 필요하면 쉬운 한국어로 먼저 설명하고, 원문 용어는 처음 한 번만 함께 쓴다.
- 정확한 비교나 복잡한 관계를 실제로 더 쉽게 이해할 수 있을 때만 표, Mermaid 또는 사용 가능한 대화형 표현을 선택한다. 대화형 기능이 항상 제공된다고 가정하지 않는다.
- 단순한 내용은 글이나 목록으로 설명하며 다이어그램을 강제하지 않는다.
- 표·다이어그램·대화형 표현에는 핵심을 이해할 수 있는 글 대안을 함께 제공해 접근성을 지킨다.
