완료 전환에서 제외한 보류 범위

아래 항목은 docs/scope-decisions/2026-06-17-ai-deferred-and-mvp-scope.md 기준으로 active 개발 완료 기능처럼 취급하지 않는다.

  • 결제 provider checkout, 결제수단 변경, 취소 write-back, webhook
  • email/Zalo/push 외부 발송 transport
  • 정식 법무 문구, 정책 versioning, 재동의/삭제 요청 운영 flow
  • 실제 LLM 품질 보장, AI 사용량 한도, 작성 중 AI 대화 피드백
  • 유료 고급 비교 분석과 운영 정책이 필요한 기능

팩트 체크 인사이트

  • Supabase Storage 다운로드는 bucket object에 대한 권한 정책을 통과해야 하므로, export history 재다운로드는 저장된 storage_path를 Storage API download로 처리하는 방식이 맞다. Supabase download 문서
  • Storage object 삭제 역시 Storage API로 처리해야 파일 객체가 실제로 제거된다. 이번 아바타 삭제는 사용자 폴더 경로만 삭제 대상으로 제한했다. Supabase delete objects 문서
  • Next.js App Router에서는 app 디렉터리의 route handler가 서버 API endpoint 역할을 한다. evaluation status 동기화 route도 이 구조를 따른다. Next.js Route Handlers 문서

이 문서는 기존 active SOT를 직접 수정하지 않고, docs/todo/ 아래의 구현 보고 산출물로 작성했다. 실제 SOT 상태 변경이 필요하면 별도 docs/sot-change-proposals/ 제안으로 분리한다.
