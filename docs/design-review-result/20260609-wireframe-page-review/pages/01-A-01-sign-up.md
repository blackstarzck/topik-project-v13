## 4. Layer 2 — 멀티 에이전트 독립 분석

- **콘텐츠/데이터 (정직 seam)**: "**소셜 로그인(구글·카카오 등)은 준비 중이에요. 지금은 이메일로 가입할 수 있어요**" — 미구현(소셜)을 정직 표기. SOT #4의 "소셜 로그인"을 가짜로 만들지 않음(좋음).
- **UX/IA (양호)**: 약관·개인정보 동의 체크(링크 포함)가 가입 게이트. 혜택 칩으로 가치 전달. "이미 계정이 있으신가요? 로그인" 전환 경로.
- **UX (P2, 경미)**: SOT #4 "필수값 충족 전 CTA 비활성"인데 antd Form은 제출 시 검증(버튼 항상 활성 추정 — [[02-A-02]]와 동일 패턴). 기능 문제는 없음.
- **반응형/접근성 (양호)**: 카드 중앙 정렬, 입력 라벨·show/hide·약관 링크 존재.
- **상태 커버리지 (양호)**: 중복 이메일/형식 오류/메일 발송 실패 분기는 코드/SOT상 정의(미발생).
- **적대적 검증**: 핵심(폼·약관 동의·정직 소셜 seam) 일치 확정. CTA 비활성 차이는 경미.
