# 19-F-M1 PDF 내보내기 모달 — 와이어프레임 기준 리뷰

## 1. 메타
- **IA / 라우트**: F-M1 / (host: 내 서재 `/library`)
- **audience**: user
- **캡처 상태**: rendered (시드된 보관함 항목 선택 → "PDF로 내보내기" → 모달 캡처 → 닫기)
- **host**: 내 서재 위 모달(`PdfExportModal`)

- 스크린샷: `.design-review-shots/20260609/19-F-M1-pdf-export-modal-{360,1280}.png`

**종합 verdict: 부분일치(경미)** — 구조·옵션·게이트는 일치, 미리보기에 사람이 읽을 수 없는 식별자 노출 1건.

## 4. Layer 2 — 멀티 에이전트 독립 분석

- **콘텐츠/데이터 (P2)**: 미리보기 항목이 **"문제 11111111"** — 문제의 원시 UUID 접두사를 그대로 표시. 사람이 읽을 "51번" 또는 문제 제목이어야 자연스러움. 사용자가 어떤 항목을 내보내는지 식별하기 어려움.
- **UX/IA (양호)**: 옵션이 논리적 묶음(파일명→포함 항목→정렬→형식→동의). 개인정보 동의 체크가 내보내기 게이트로 작동(SOT "개인정보 확인 필수" 정합). 미리보기로 결과 예측 가능.
- **상태 커버리지 (양호)**: 선택 0개면 상단 버튼 비활성(SOT "선택 없음 안내"). 생성 실패/권한 잠금(유료→X-03)은 코드/SOT상 정의(이번 캡처 미발생).
- **비주얼 (양호)**: antd 폼 컨트롤 일관, 미리보기 카드 명확. ("1 Issue" dev 배지는 내 서재의 antd 폐기 경고 계열로 추정 — 별도 점검 대상.)
- **반응형 (양호)**: 1280/360 모달 폭·옵션 가독.
- **적대적 검증**: "미리보기 UUID 노출"은 캡처로 확정(과장 아님). 다른 영역 일치도 확인.

## 5. 결론 — 개선안

### P0 / P1
- 없음.

### P2 (여유 있을 때)
- **미리보기 항목 라벨 개선**: "문제 11111111"(UUID) → "51번 — <문제 제목>" 같은 사람이 읽을 표기로. — 근거: Layer 2 콘텐츠/데이터, 증거 = 19-F-M1 캡처. 영향: PDF 내보내기 미리보기(내 서재·피드백 진입 모두).
