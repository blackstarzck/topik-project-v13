# 02-A-02 로그인 — 와이어프레임 기준 리뷰

## 1. 메타
- **IA / 라우트**: A-02 / `/login` (+ `?reason=session_expired` 변형)
- **audience**: public
- **캡처 상태**: rendered (완전 하이드레이션 확인 — Segmented·show/hide 토글 동작)
- **host**: 단독 페이지

## 2. 캡처 증거
- 스크린샷: `.design-review-shots/20260609/02-A-02-login-{360,768,1280}.png`, `02-A-02-login-session-expired-{360,768,1280}.png`
- 렌더 헬스(`_health.json`): HTTP 200, 콘솔 에러 0, 에러 오버레이 없음.
- 캡처 도구 주의: 이 화면은 자기 자신이 `/login`이라 "LOGIN-REDIRECT" 휴리스틱이 **오탐**으로 떴으나, 실제로는 완전 렌더된 정상 화면(비밀번호/매직링크 Segmented, 이메일·비밀번호 입력, show/hide 토글 모두 동작).

| 항목 | 요소/상태/문구 | 판정 | 근거 |
| --- | --- | --- | --- |
| 환영/브랜드(#1) | "다시 오신 걸 환영해요" 제목 + 보조문 | 있음 | 캡처 |
| 마스코트(#2) | 학습 보조 캐릭터(병아리) | 있음 | 캡처 상단 이모지 |
| 로그인 폼(#3) | 이메일/비밀번호, blur 검증, 비밀번호/매직링크 전환 | 있음 | 캡처: Segmented + 두 입력 |
| 로그인 CTA(#4) | 로그인 버튼 + 가입/찾기 링크 | 있음(경미한 차이) | 캡처: "로그인" + "비밀번호를 잊으셨나요?" + "계정이 없으신가요? 회원가입" |

**종합 verdict: 부분일치(경미)**
- 핵심 인증 흐름·문구·세션 만료 안내는 SOT와 일치.
- 차이 2건(아래 Layer 2): ① 소셜 로그인 미노출, ② CTA 비활성 정책.

## 4. Layer 2 — 멀티 에이전트 독립 분석

- **UX/IA (P2)**: SOT #4 제약 "필수값 충족 전 CTA 비활성"인데, 실제 로그인 버튼은 입력 전에도 활성(antd Form은 제출 시 검증). 기능상 문제는 없으나 명세와 다름. 매직링크/비밀번호 분리는 명확하고 인지부하 낮음(양호).
- **콘텐츠/i18n (양호)**: 한글 카피 자연스러움. 문구가 SOT 톤과 정렬.
- **상태 커버리지 (양호)**: 세션 만료 변형에서 인라인 안내 노출. 실패 횟수 힌트(3회)·rate-limit→X-11 카드 분기는 코드상 정의됨(이번 캡처는 미발생, UNVERIFIED-LIVE).
- **반응형/접근성 (양호)**: 360/768/1280 카드 중앙 정렬 유지, 입력 라벨·show/hide 토글 존재.
- **콘텐츠 (관찰)**: description 분기의 "소셜 로그인"이 화면엔 없음 — 정책상 비채택일 수 있음. SOT 문서와 화면 중 무엇이 최신인지 정렬 필요.
- **적대적 검증**: "CTA 비활성 누락"·"소셜 로그인 없음" 모두 캡처로 확인(확정, 단 심각도는 낮음).

## 5. 결론 — 개선안

### P0 / P1
- 없음 (핵심 로그인 기능 정상).

### P2 (여유 있을 때)
- **소셜 로그인 정렬**: SOT 분기 문구의 "소셜 로그인"을 채택 안 한다면 description에서 제거(문서-화면 불일치 해소), 채택한다면 화면에 추가. — 근거: Layer 1 문서-코드 차이.
- **CTA 비활성 정책 정렬**: SOT가 "필수값 충족 전 비활성"을 원하면 버튼 disabled 로직 추가, 아니면 SOT 문구 완화. — 근거: Layer 2 UX. 영향: 로그인 화면만.
