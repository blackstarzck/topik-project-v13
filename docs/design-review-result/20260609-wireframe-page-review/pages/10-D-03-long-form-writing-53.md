## 4. Layer 2 — 멀티 에이전트 독립 분석

- **데이터/코드 (P1, 단 q53 화면 결함 아님)**: 직접 URL 진입(파라미터 없음) 시 `getWritingProblem`이 `ORDER BY` 없이 `.limit(1)`로 골라 빈 시드 예시(`3333…`)가 로드됨 → "평가 기준 불러오지 못함". 실제 문제(46/47 완비)로 진입하면 정상. → 근본 조치는 **기본 선택에 정렬 추가 + 빈 예시 unpublish**([[09-D-02]] 공통).
- **UX/IA (우수)**: 섹션 탭(도입/전개/마무리) + 원고지 미리보기는 장문 작성 보조로 우수. 자료 결손 시 사유+수동 점검 안내 명확.
- **콘텐츠/i18n (P2)**: 빈 예시 제목 "53번 — TOPIK 53번 — 도표 분석 (예시)" 이중 접두사(예시 문제에 한정).
- **상태 커버리지 (양호)**: 자료 결손/정상 모두 적절히 분기.
- **반응형/접근성 (양호)**: 좌(문제/에디터)/우(도움말) 2단, 원고지 그리드 가독.
- **적대적 검증**: 초기 "콘텐츠 결손" 주장을 실측으로 반증 → **철회**. q53 실 데이터는 정상.

## 5. 결론 — 개선안

### P1 (이번 주 안에)
- **기본 문제 선택 정렬 추가** + **빈 시드 예시 unpublish**: 파라미터 없는 진입(딥링크 등)에서 빈 예시가 뜨지 않게. q53 화면 자체는 정상이므로 이 조치로 해결. ([[09-D-02]]·[[11-D-04]] 공통 근본)

### P2 (여유 있을 때)
- 빈 예시 제목 이중 접두사 정리(예시 문제 정규화).
