- **UX/IA (양호)**: 단일 목적(이메일→재설정 링크) 명확. Stepper 제거(가짜 단계 방지) 결정과 정합. 로그인 복귀 escape 존재.
- **콘텐츠/i18n (양호)**: 안내 카피 평이.
- **상태 커버리지 (양호)**: cooldown/발송 실패는 코드/SOT상 정의(미발생). 발송 후 성공 안내 상태는 미캡처(UNVERIFIED-LIVE).
- **반응형/접근성 (양호)**: 중앙 카드 360 유지, 이메일 라벨 존재.
- **콘텐츠 (nit)**: SOT #5 마스코트 미노출 — 의도적 단순화 가능. 문서-화면 정렬 점검.
- **적대적 검증**: "마스코트 없음" 캡처 확정(경미). 핵심 흐름 일치.
