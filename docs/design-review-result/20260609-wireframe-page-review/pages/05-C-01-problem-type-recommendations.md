## 4. Layer 2 — 멀티 에이전트 독립 분석

- **데이터/UX (P1, 시스템적)**: **대표 추천이 "52번"(차단된 placeholder)** — "이 문제부터 시작하기"를 누르면 조건 결손으로 막힌 D-02 화면으로 감([[09-D-02]]). 대시보드([[04-B-01]])·R-02([[17-R-02]])도 동일하게 52를 추천 → **추천 시스템 전반이 작성 불가 문제를 가리킴**. 근본 원인은 쓰기 문제 콘텐츠 결손([[10-D-03]] 시스템 패턴).
- **콘텐츠/i18n (P2)**: "보완 포인트"에 원시 코드 노출 — `topic_fit`(주제 적합성), `audit_seed`(시드 마커). 사람이 읽을 라벨(예: "주제 적합성")로 변환 필요. `audit_seed`는 실데이터에선 사라짐.
- **UX/IA (양호)**: 추천 근거 안내 + 대표 추천 강조 + 직접 선택 카드의 위계 명확.
- **반응형/접근성 (양호)**: 탭 가로 스크롤, 카드 4열→스택. 깨짐 없음.
- **상태 커버리지 (양호)**: 추천 사유 안내. 추천 계산 실패/빈 결과는 코드/SOT상 정의(미발생).
- **적대적 검증**: "추천이 차단 문제를 가리킴" → 캡처+D-02로 확정. "C-01 자체 결함"은 아니며 데이터 결손의 전파로 표기.

## 5. 결론 — 개선안

### P1 (이번 주 안에)
- **추천 후보에서 작성 불가(콘텐츠 결손) 문제 제외** 또는 **52번 정상 콘텐츠 확보**([[09-D-02]]·[[10-D-03]] P1과 동일 근본). 추천을 따라가도 막히지 않도록.

### P2 (여유 있을 때)
- **"보완 포인트" 코드 라벨화**: `topic_fit`→"주제 적합성" 등 사람이 읽을 표기, `audit_seed` 마커 비노출.
