이 리뷰를 진행하기 위해 고쳐야 할 문서는 **없습니다**. 아래는 "나중에 소유자가

## 1. 배경 — 왜 충돌이 아닌가

- `docs/admin-scope-boundary.md`(2026-06-02, 소유자 권위 지시)는 이미 admin을
  **동결된 별도 영역**으로 규정: "이 저장소는 사용자용 앱이며, admin은 지금 만들지·
  확장하지·remediate하지 않는다. admin은 다른 곳에서 소유되고 나중에 reconcile한다."
- 이번 리뷰 결정(admin 화면을 **읽기 전용 디자인 리뷰 대상에서 제외**)은 그 동결
  규정의 **자연스러운 귀결**입니다. "리뷰 제외"는 "동결"과 같은 방향이라 새 충돌이
  생기지 않습니다.
- 따라서 **이 리뷰는 admin 경계 문서를 건드리지 않고** admin 4개 화면을 인덱스에
  "관리 대상 / 범위 밖(별도 admin 앱 소관)"으로만 표기합니다.

## 2. 주의 — 닫으면 안 되는 게이트

`docs/admin-scope-boundary.md` 상단에는 **OVERLAP INTEGRATION GATE — OPEN
(2026-06-08, 소유자 승인)** 이 있습니다. 회원/문제/결제(읽기) 3개 overlap 도메인은
topik-ai(별도 repo)에서 v13 스키마로 데이터 정합 작업이 **진행 중**입니다.
→ "admin 정리" 제안을 적용할 때 이 **열린 게이트를 닫는 방향으로 문구를 바꾸면 안
됩니다.** ("admin 일절 금지"로 되돌리면 진행 중인 overlap 작업과 모순됩니다.)
