## 요약

Across 35 pages, the TALKPIK design system is structurally sound on macro-layout but leaks consistently at the token boundary: 0 pages are clean, with theme the weakest axis (8 fail / 21 warn) and design and antd both dominated by warns. The single most pervasive defect is inline magic-number px values for spacing/fontSize (≈25 pages) and the off-scale fontSize 13 in particular, followed by hand-authored #hex/rgb literals in src/app and src/components (≈11 pages, including duplicates of the existing --app-color-primary #1677ff token). The highest-leverage structural bug is that every workspace writing/feedback/report/onboarding page omits PageHeader, so they emit zero <h1> instead of exactly one — this alone drives 9 layout fails. Antd-specific debt is lower-volume but real: a deprecated antd List on a sortable record table (C-02), deprecated Steps items.description and browser-native window.confirm/alert in the analysis-loading modal (D-M2), and a non-modal "modal" (AnalysisLoadingModal renders a bare AppCard with no overlay). Net: the foundation (AppCard, AppModal, SPACING, --app-* bridge vars, PageHeader) all exist and are partially adopted — remediation is mostly mechanical reconciliation TO existing tokens/wrappers, not new design work.

## 시스템 전반 패턴 (레버리지 큰 순)

1. INLINE MAGIC-NUMBER px (spacing/fontSize) — the dominant defect, confirmed on ~25 of 35 pages (A-01, A-02, A-03, B-01, C-01, C-02, C-03, D-01..D-04, D-M1, D-M2, D-M3, E-01, E-02, R-01, R-02, F-01, F-M1, G-01, X-01, X-03..X-09, X-12..X-17). SPACING (src/theme/spacing.ts {4,8,16,24,32}) exists and is adopted in only a handful of files; the fix is mechanical: swap literals for SPACING.* / a class / // ai-check.
2. OFF-SCALE fontSize 13 (and 18) — a recurring sub-pattern of the above: fontSize:13 confirmed on A-01, A-02, A-03, C-01, D-02, D-03, X-01, X-12 (and 18 on R-02/X-01). 13 is off the 24/20/16/14/12 type ladder; should be 12 or 14 (or default).
3. HAND-AUTHORED #hex/rgb in src/app & src/components — confirmed on ~11 pages (A-01, B-01 via raw Card, C-01, D-03, R-01, R-02, X-01, X-02, X-07, F-M1-adjacent, X-16). The literal #1677ff recurs as a hardcoded duplicate of the existing --app-color-primary token (C-01, R-01, R-02, X-01, X-02, X-07); charts (#bfbfbf/#52c41a/#eee) and borders (#d9d9d9) are the other repeat offenders. Dark-mode drift results.
4. MISSING PageHeader -> zero <h1> on workspace pages — confirmed on every writing/feedback/report/onboarding page (A-03, D-01, D-02, D-03, E-01, E-02, R-01). PageHeader.tsx emits exactly one <h1> and is already used by 6-11 sibling workspace pages (profile/settings/library/practice/next+weakness); these pages render their title as Title level={3/4/5} in-card instead. X-13 is the public-page analogue (h2-as-title, zero <h1>).
5. MULTIPLE Button type="primary" co-rendering in one task area — R-02 (2), X-02 (up to 5), X-07 (up to 4), F-M1 (done/error states), E-02 (empty-recommendations state). Violates the one-primary-per-area rule; fix is demoting per-item/secondary buttons to default.
6. RAW antd component instead of App* wrapper — B-01 uses raw <Card> (x2) where AppCard exists; D-M2's AnalysisLoadingModal uses a bare AppCard with no AppModal/overlay. Wrappers exist (AppCard/AppModal) and carry the theme hooks; consumers bypass them.
7. OFF-RHYTHM gap/margin value 12 and Space size={10} — 12px recurs on margins (C-03, D-M1, D-M3, F-M1, X-04, X-05, X-09, etc.) and Space size={10} on plan cards (X-03, X-04); both off the 8-based 4/8/16/24/32 scale.

## 권장 수정 순서

- 1. Add PageHeader to the 8 workspace/public pages missing an <h1> (A-03, D-01, D-02, D-03, E-01, E-02, R-01, X-13) — clears 8 of 9 layout fails with one well-established pattern; route page-level primary actions (Share, Submit) into PageHeader's actions slot.
- 2. Replace hand-authored #hex/rgb with --app-* bridge vars / antd tokens across the 11 theme-fail pages, prioritizing the #1677ff -> var(--app-color-primary) duplicates (C-01, R-01, R-02, X-01, X-02, X-07) and chart strokes (X-02, R-01, B-01-charts) — this also fixes dark-mode drift, the highest-severity systemic theme defect.
- 3. Convert raw antd Card -> AppCard on B-01 (RecentFeedbackCard, UpcomingExamCard) and wrap D-M2's AnalysisLoadingModal in AppModal with a real dimmed read-only overlay — restores theme hooks and correct modal overlay semantics.
- 4. Fix the antd deprecation/native-dialog cluster: C-02 List -> Table (sortable records), D-M2 Steps items.description -> content, D-M2 window.confirm/window.alert -> Modal.confirm/message — these are forward-compat blockers on antd 6.x.
- 5. Resolve the multiple-primary-button violations (R-02, X-02, X-07, E-02, F-M1) by demoting per-item/secondary CTAs to default, and add non-color selection cues (Tag/icon + aria-pressed) where color is the sole signal (R-02, AlternativeCardsGrid).
- 6. Sweep inline magic-number px in bulk: introduce/adopt SPACING tokens and a small set of CSS utility classes, snap off-rhythm 12/10 values to the 8-grid, and replace off-scale fontSize:13/18 with 12/14 — mechanical pass across the ~25 affected pages, lowest-risk last.
- 7. Address the remaining low/med one-offs: A-02 missing social-login surface (confirm scope vs doc), R-01 chart error boundary -> Result/table fallback, E-01 inverted-severity Alert + missing recovery action, X-05 raw <input type=file> -> antd Upload + region-4 visibility/policy wiring, X-12 inline Form validation, X-09 CheckableTag disabled prop + Tabs-as-mode-picker, X-11 next/link legacyBehavior removal.
