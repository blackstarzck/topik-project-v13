# X-14 개인정보처리방침 화면 데이터 계약

## 화면 요약
개인정보 처리 기준, 공개 일자, 버전을 보여주는 정책 화면이다.

이 문서는 사용자 화면이 소비하는 운영/관리 대상 데이터만 정리한다. 관리자 전용 화면 구현이나 관리자 스키마 확장은 이번 범위에 포함하지 않는다.

## 사용자 화면 표시 데이터
- 개인정보처리방침 제목
- 버전/공개 일자
- 본문
- 문의/삭제 요청 안내
- 관련 링크

## 사용자 입력/상태 데이터
- 스크롤 위치
- 문의 링크 클릭
- 삭제 요청 링크 클릭

## 운영/관리 대상 데이터 계약
| 데이터 | 분류 | 확정 계약 | 메모 |
| --- | --- | --- | --- |
| 정적 개인정보처리방침 페이지 | DB 계약 없음 | 현재 public schema에는 방침 본문을 읽는 테이블/RPC가 없다. | 정적 문서 또는 앱 콘텐츠로 표시한다. |
| 정책 본문/버전/공개 일자 | 스키마 보강 필요 | 방침 본문, 버전, 공개 일자, 적용 일자를 운영 데이터로 관리하는 구조는 없다. | 정책 개정 이력과 동의 이력 구조가 없다. |
| 삭제/열람 요청 | 스키마 보강 필요 | 개인정보 요청 ticket 또는 ledger를 저장하는 public schema 구조는 없다. | 지원 채널로 처리하는 경우에도 데이터 계약이 필요할 수 있다. |

## Supabase 테이블 스키마 정보
현재 public schema migration에서 이 화면 전용 테이블/RPC/storage 계약은 없다. Supabase Auth 또는 정적 콘텐츠 흐름은 앱 DB 계약과 분리한다.

## 저장/조회/이벤트 흐름
화면은 정적 방침 콘텐츠를 렌더링한다. 문의나 삭제 요청 링크는 별도 지원 채널로 이동한다.

## RLS/권한 기준
- public schema 접근이 없다.
- 정책 페이지는 로그인 여부와 무관한 정적 화면이다.

## 스키마 정합성 메모
정책 본문과 요청 이력은 현재 스키마에 없다. 화면 표시 자체는 DB 계약 없음이다.

## 검수 필요 항목
- 방침 본문 저장소와 버전 관리 방식을 정한다.
- 삭제 요청을 앱 DB에 남길지 외부 지원 도구로 둘지 정한다.
