## Detailed Description

### 36 X-14 개인정보처리방침

1
■ 개인정보 안내 페이지

▣ 설명
• 회원가입 동의 흐름과 약관 페이지에서 연결되는 공개 개인정보 안내 화면이다.
• 현재 구현은 한국 개인정보보호법 준수 사항을 반영하기 전 placeholder임을 명확히 고지한다.
• 학습 데이터와 글쓰기 제출물이 어떤 목적으로 쓰이는지 사용자가 이해할 수 있어야 한다.

2
■ 처리 항목 요약

▣ 설명
• 수집 항목: 이메일, 이름, 학습 활동 로그, 글쓰기 제출물, 평가 결과.
• 이용 목적: 계정 식별, 학습 진도 추적, AI 피드백 품질 개선.
• 보관 기간: 회원 탈퇴 시 즉시 파기, 비식별(익명) 학습 통계는 보관 가능.
• 제3자 제공: 없음. 단, AI 모델 호출 시 글쓰기 제출 본문이 외부 LLM 제공자에게 일시 전송될 수 있으며, 전송분의 보관은 모델 제공자 약관을 따른다는 점을 안내한다.

3
■ 갱신 안내

▣ 설명
• 정식 개인정보처리방침 게시 시 본 페이지가 갱신되고 가입 사용자에게 별도 안내됨을 표시한다.
• placeholder 상태와 정식 게시 예정 상태를 함께 드러낸다.

4
■ 관련 링크

▣ 설명
• X-13 이용약관, 홈, 가입 화면으로 이동할 수 있다.
• 링크는 공개 접근 가능해야 한다.

## 화면 목적

회원가입과 서비스 이용 전 개인정보 처리 범위를 확인할 수 있는 공개 policy support 페이지를 제공한다.

- 이미 로그인한 사용자: 동일 내용을 표시한다.

## 피드백

- 정식 처리방침 전 placeholder 상태를 숨기지 않는다.
- 외부 LLM 전송 가능성은 개인정보 민감 고지로 명확히 표시한다.

## 예외 상황

- 법무/개인정보 검토 전 확정적 보관 기간이나 제3자 제공 약속을 새로 만들지 않는다.
- 정식 정책 게시 시 A-01, X-13과 함께 동기화해야 한다.
