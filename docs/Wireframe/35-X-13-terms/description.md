## Detailed Description

### 35 X-13 이용약관

1
■ 법적 고지 페이지

▣ 설명
• 회원가입 약관 동의 라벨에서 연결되는 공개 약관 화면이다.
• 현재 구현은 법무 검토 전 placeholder이며, 정식 약관은 운영 전 별도 게시 예정임을 명확히 말한다.
• 사용자가 동의 대상이 무엇인지 최소한 확인할 수 있어야 한다.

2
■ 임시 약관 요약

▣ 설명
• TALKPIK AI가 TOPIK 글쓰기 학습 보조 도구임을 안내한다.
• 학습 데이터가 학습 품질 개선 목적에 쓰인다는 범위를 설명한다.
• 개인정보 처리 방식은 X-14 개인정보처리방침으로 연결한다.
• 정식 약관 게시 시 가입 사용자에게 다시 동의를 받는다는 상태를 표시한다.

3
■ 네비게이션

▣ 설명
• 홈으로 이동하는 링크와 회원가입으로 돌아가는 링크를 제공한다.
• 외부 고객지원 채널이 아직 없다는 점을 과장하지 않고 안내한다.

## 화면 목적

회원가입 동의 흐름에서 약관 내용을 확인할 수 있는 공개 legal support 페이지를 제공한다.

## 분기

- 진입: `/sign-up` 약관 동의 라벨, 직접 URL `/terms`.
- 이탈: `/`, `/sign-up`, `/privacy`.
- 세션 없음: 접근 허용.
- 이미 로그인한 사용자: 동일 내용을 표시한다.

## 피드백

- 정식 약관 전 placeholder임을 숨기지 않는다.
- 법적 효력이 확정된 문구처럼 과장하지 않는다.

## 예외 상황

- 정식 운영 채널이 없으면 문의 채널을 꾸며내지 않는다.
- 정책 문서가 갱신되면 회원가입 동의 문구와 함께 재검토해야 한다.
