## Detailed Description

### 35 X-13 이용약관

1
■ 법적 고지 페이지 (제목 + 임시 약관 안내)

▣ 설명
• 회원가입 약관 동의 라벨 및 랜딩 헤더 "이용약관" 메뉴에서 연결되는 공개 약관 화면이다.
• "이용약관" 제목과, 현재 구현이 법무 검토 전 placeholder임을 명확히 말하는 안내 문단을 함께 둔다.
• 정식 약관은 운영 전 별도 게시 예정이며 그 시점에 본 페이지가 공식 약관으로 갱신됨을 밝힌다.
• 사용자가 동의 대상이 무엇인지 최소한 확인할 수 있어야 한다.

▣ 제약 조건: 본문 폭은 읽기 편한 단일 컬럼(약 720px 이하), 안내 문단은 placeholder 사실을 숨기지 않는다.

▣ 예외: 정식 약관 게시 전까지 "확정된 법적 효력" 문구로 표현하지 않는다.

2
■ 임시 약관 요약

▣ 설명
• TALKPIK AI가 TOPIK 글쓰기 학습 보조 도구임을 안내한다.
• 학습 데이터가 학습 품질 개선 목적에 쓰인다는 범위를 설명한다.
• 개인정보 처리 방식은 X-14 개인정보처리방침(`/privacy`)으로 연결한다.
• 정식 약관 게시 시 가입 사용자에게 다시 동의를 받으며, 현재 가입은 본 임시 안내 동의로 처리됨을 표시한다.

▣ 제약 조건: 항목은 목록으로 제공하고, 외부 LLM 전송 등 사실과 다른 보장은 적지 않는다.

▣ 예외: 없음.

3
■ 운영 문의 안내

▣ 설명
• 정식 운영 채널(고객지원)이 아직 준비되지 않았다는 점을 과장 없이 안내한다.
• 가입 후 문제가 생기면 인증 오류 페이지의 안내를 참고하도록 연결한다.

▣ 제약 조건: 존재하지 않는 문의 채널(이메일/전화 등)을 꾸며내지 않는다.

▣ 예외: 없음.

4
■ Escape 링크

▣ 설명
• 홈(`/`), 회원가입(`/sign-up`), 개인정보처리방침(`/privacy`)으로 이동하는 링크를 제공한다.
• 사용자가 약관 화면에서 막다른 길에 갇히지 않도록 항상 최소 1개 escape를 노출한다.

▣ 제약 조건: 항상 노출, 키보드 접근성 확보.

▣ 예외: 회원가입에서 새 탭으로 열린 경우 "가입으로 돌아가기"는 동일 탭 네비게이션이며, 사용자는 탭을 닫아 가입 흐름으로 복귀할 수도 있다.

## 화면 목적

회원가입 동의 흐름에서 약관 내용을 확인할 수 있는 공개 legal support 페이지를 제공한다.

## 분기

- 진입: `/sign-up` 약관 동의 라벨(새 탭), 랜딩 헤더 "이용약관" 메뉴(`X-01`), 직접 URL `/terms`.
- 이탈: `/`, `/sign-up`, `/privacy`.
- 세션 없음: 접근 허용 (`PUBLIC_PATHS`에 포함).
- 이미 로그인한 사용자: 동일 내용을 표시한다 (분기 없음).

## 피드백

- 정식 약관 전 placeholder임을 숨기지 않는다.
- 법적 효력이 확정된 문구처럼 과장하지 않는다.

## 예외 상황

- 정식 운영 채널이 없으면 문의 채널을 꾸며내지 않는다.
- 정책 문서가 갱신되면 회원가입 동의 문구와 함께 재검토해야 한다.
