# 2026-06-25 문제 목록 풀이 상태 컬럼 제거 제안

## 결론

문제 목록(C-02) 테이블에서는 별도 `풀이 상태` 컬럼을 제거하고, 학습자의 다음 행동은 오른쪽 CTA(`시작하기` / `다시 풀기`)와 `이전 점수` 값으로 구분한다.

## 현재 구현

- `src/components/practice/ProblemTable.tsx`는 `문제`, `난이도`, `예상 시간`, `이전 점수`, 오른쪽 액션만 렌더한다.
- `solveState` 데이터는 계속 사용한다. 행 클릭 시 미풀이 문제는 작성 화면으로 이동하고, 이전 풀이가 있는 문제는 다시 풀기 모달을 연다.
- 문제 목록의 풀이 상태 필터는 유지한다. 이번 결정은 필터 제거가 아니라 테이블 표시 컬럼 제거만 다룬다.

## 기존 SOT와의 차이

`docs/Wireframe/06-C-02-problem-list/description.md`에는 문제 목록 행이 `상태`를 표시하고, 상태 배지 1개를 우선한다고 되어 있다. 현재 구현은 상태 배지를 노출하지 않고 CTA와 이전 점수로 같은 정보를 전달한다.

| 항목 | SOT 근거 | 제안 상태 |
| --- | --- | --- |
| 문제 목록 행의 상태 표시 | `description.md` Wireframe Number Map 4, Detailed Description 4 | 별도 컬럼/배지 제거 |
| 상태 배지 1개 우선 | `description.md` Detailed Description 4 제약 조건 | CTA와 이전 점수로 대체 |
| 풀이 상태 필터 | `description.md` Wireframe Number Map 2, `functional-spec.md` 데이터 사용 | 유지 |

## 결정 근거

- 현재 상태가 `완료` / `미풀이` 중심이면 오른쪽 CTA가 이미 `다시 풀기` / `시작하기`로 같은 의미를 전달한다.
- `이전 점수`가 있는 행은 이전 풀이가 있음을 함께 보여준다.
- 상태 필터나 다시 풀기 모달 동작에는 영향을 주지 않는다.

## 검증 기준

- C-02 테이블에 `풀이 상태` 컬럼 헤더와 상태 배지가 렌더링되지 않는다.
- `시작하기` / `다시 풀기` CTA는 계속 표시된다.
- 미풀이 행 선택은 작성 화면으로 이동하고, 이전 풀이가 있는 행 선택은 C-03 다시 풀기 모달을 연다.
- desktop/mobile viewport에서 `/practice/problems`가 정상 렌더링된다.
