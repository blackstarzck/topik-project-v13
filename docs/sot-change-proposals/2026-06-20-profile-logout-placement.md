# 프로필 하단 로그아웃 배치 제안

- 작성일: 2026-06-20
- 제안 상태: implementation-aligned proposal
- 관련 요청: 사이드바 하단 학습 문구 제거, 로그아웃 버튼을 설정 > 프로필 하단으로 이동

## 배경

사용자 요청에 따라 워크스페이스 사이드바 하단의 학습 문구와 로그아웃 버튼을 제거하고, 로그아웃 버튼을 프로필 화면 하단으로 이동한다.

현재 active SOT에는 로그아웃 위치가 사이드바 하단으로 남아 있어 구현 방향과 문서가 어긋난다.

## 충돌한 SOT

| 문서 | 현재 내용 | 충돌 이유 |
| --- | --- | --- |
| `docs/flow/user-flow.md` | B-01에서 `로그아웃 (사이드바 하단, POST /auth/sign-out)` 흐름을 명시 | 로그아웃 진입점이 프로필 화면 하단으로 이동함 |
| `docs/Wireframe/share/03-learner-side-nav-state/sidebar-navigation-decision-summary.md` | `로그아웃`을 `하단 액션`으로 분류 | 사이드바 하단 액션이 아니라 계정/프로필 하단 액션으로 바뀜 |
| `docs/qa/plan/first-remediation-execution-plan-20260612.md` | G6 로그아웃 UI를 워크스페이스 사이드바 하단에 추가한 계획을 기록 | 과거 계획 기록으로 남길 수 있으나, 최신 기준과 구분이 필요함 |

## 제안 변경

1. `docs/flow/user-flow.md`의 로그아웃 흐름을 B-01 사이드바 하단이 아니라 X-05 프로필 편집 하단에서 A-02 로그인으로 이동하는 흐름으로 갱신한다.
2. `sidebar-navigation-decision-summary.md`에서 로그아웃을 사이드바 하단 액션이 아니라 설정/프로필 하단 계정 액션으로 재분류한다.
3. QA 문서는 과거 기록은 유지하되, 최신 테스트 기준은 프로필 하단 로그아웃으로 바뀌었음을 별도 최신 QA 항목 또는 실행 기록에 남긴다.

## 수용 기준

- 사이드바에는 학습 문구와 로그아웃 버튼이 보이지 않는다.
- `/profile` 화면 하단에는 `POST /auth/sign-out`을 사용하는 로그아웃 버튼이 보인다.
- 로그아웃 후 `/login`으로 이동하고, 보호 화면 재접근 시 로그인 화면으로 돌려보낸다.
- 변경된 로그아웃 위치가 `docs/flow/user-flow.md`, 사이드바 판단 문서, e2e 테스트 이름과 일치한다.

## 검토한 대안

| 대안 | 판단 |
| --- | --- |
| 사이드바 하단 로그아웃 유지 | 사용자 요청과 충돌하므로 제외 |
| 설정 메뉴 하위에 별도 로그아웃 route 추가 | route와 화면이 늘어나므로 현재 요청 범위를 초과 |
| 프로필 하단에 form POST 버튼 배치 | 기존 `/auth/sign-out` 처리 흐름을 재사용하고 범위가 가장 작음 |
