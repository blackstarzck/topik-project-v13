# A-03 학습 목표 설정 stepper/CTA 단순화 제안

## 제안 요약

`/onboarding/learning-goal` 화면에서 상단 온보딩 진행 단계(stepper)를 제거하고,
이전 단계 수정 버튼을 제거한다. `건너뛰기` CTA는 메인 저장 CTA 바로 아래에
같은 폭의 텍스트 버튼으로 배치한다.

## 변경 이유

- 사용자가 현재 화면에서 목표 입력에만 집중하도록 상단 진행 표시를 줄인다.
- 이전 단계 수정 버튼은 이메일 인증 이후 사용자가 되돌아갈 실질 행동 가치가
낮아 현재 온보딩 화면의 주요 행동을 흐린다.
- `건너뛰기`는 보조 행동이므로 저장 CTA 아래에 같은 폭으로 두되, 배경과
outline이 없는 텍스트 버튼으로 시각적 우선순위를 낮춘다.

## 영향 문서

- `docs/Wireframe/03-A-03-learning-goal-setup/description.md`
  - `Wireframe Number Map`의 `1 | 온보딩 진행 단계` 제거 또는 비노출 상태로 변경
  - `4 | 이전/다음 CTA`를 저장 CTA와 건너뛰기 CTA 중심으로 갱신
- `docs/Wireframe/03-A-03-learning-goal-setup/functional-spec.md`
  - 코드 구현 근거에서 `OnboardingSteps` 사용 여부 재검토

## 수용 기준

- 화면 상단에 `3/3 단계`, `계정 생성`, `이메일 인증`, `학습 목표` stepper가
  표시되지 않는다.
- `이전 단계 수정` 버튼이 표시되지 않는다.
- `건너뛰기`는 `저장하고 대시보드로 이동` 아래에 같은 폭의 text button으로
  표시된다.
- `건너뛰기` 클릭 시 기존처럼 기본 학습 목표를 저장한 뒤 대시보드로 이동한다.
