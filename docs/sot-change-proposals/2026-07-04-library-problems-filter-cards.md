## 변경 이유

`/library/problems`는 저장 답안과 저장 문제를 단일 혼합 리스트로 보여주지만, 유형(저장 답안/저장 문제)이나
분석 상태(분석 대기/중/완료/실패)별로 좁혀 보는 수단이 검색어 입력뿐이다. 사용자 결정(2026-07-04)으로
검색 툴바 하단에 유형·상태 필터 카드 그리드를 추가한다.

## 사용자 결정 기록 (2026-07-04)

| 질문 | 결정 |
| --- | --- |
| 카드의 체크박스 동작 | 목록 필터 토글 (다중 선택 패싯) |
| 상단 탭(전체/저장 답안/저장 문제) | 완전 제거, 필터 카드만 사용 |
| 카드 카테고리 범위 | 유형+상태 전체 (8종) |

검토한 대안: (a) 탭 + 카드 병행 → 역할 중복으로 기각, (b) 카드 표시 전용(동작 없음) → 필터 수단 부재
지속으로 기각, (c) 일괄 선택 후 액션 → 내보내기 흐름과 중복이라 기각.

## 제안 범위

- 검색 툴바 하단에 필터 카드 8종을 그리드(왼→오)로 나열한다:
  `저장 답안`, `분석 대기`, `분석 중`, `분석 완료`, `분석 실패`, `저장 문제`, `제공 종료`, `이용 불가`.
- 각 카드는 `라벨 + 개수 + 끝(오른쪽) 체크박스`로 구성한다.
- 체크박스는 다중 선택 필터다. 체크된 카테고리의 **합집합(OR)** 을 목록에 표시하고, 미체크 시 전체를 보여준다.
  - OR 선택 근거: `저장 답안`은 상태 4종의 상위 집합이라 AND 결합 시 빈 결과가 잦고 예측이 어렵다.
- 카드 개수는 **검색어 적용 후, 카드 필터 적용 전** 집합 기준이다(패싯 카운트: "이 카드를 체크하면 몇 건이
  보이는가"에 답한다). 체크 상태는 개수에 영향을 주지 않는다.
- 0건 카테고리도 카드를 유지하고 0을 표시한다(레이아웃 안정). 단, 저장 항목이 하나도 없으면 그리드 전체를
  숨기고 기존 빈 상태만 보여준다.
- 카드 필터로 결과가 0건이면 필터 전용 빈 상태(`emptyFiltered`)와 `필터 초기화` 버튼을 노출한다.
  검색어가 함께 있으면 기존 `emptySearch` + `검색 초기화`(검색어와 체크 모두 해제)를 우선한다.
- 상단 탭은 도입하지 않는다. 필터 상태는 URL에 영속하지 않는다(기존 검색어와 동일한 컴포넌트 상태 유지).
- 분석 상태 데이터는 기존 `fetchSubmissionEnrichment` 결과를 재사용한다. enrichment 로딩 전에는 행 배지와
  동일하게 `pending`으로 집계된다(기존 배지 동작과 일치).

## 데이터 계약

- 추가 DB 조회, 테이블, RPC 변경 없음. 기존 `library_items` 조회와 `writing_submissions.feedback_status` /
  `writing_feedback` enrichment만 사용한다.

## 수용 기준

- `/library/problems`는 `검색 패널 + 필터 카드 그리드 + 혼합 리스트 + 페이지네이션` 구조를 가진다.
- 필터 카드 8종이 왼→오 그리드로 나열되고, 각 카드에 라벨/개수/체크박스가 보인다.
- 카드 체크 시 해당 카테고리 항목만(복수 체크 시 합집합) 목록에 남고 페이지는 1로 초기화된다.
- 체크 해제 또는 초기화 시 전체 목록이 복원된다.
- 카드 필터만으로 0건이 되면 `emptyFiltered` 문구와 `필터 초기화` 버튼이 보인다.
- 저장 항목이 전혀 없으면 필터 카드 그리드는 렌더링되지 않는다.
- desktop/mobile 모두 가로 오버플로 없이 렌더링된다 (mobile 2열, sm 이상 4열).
- ko/en/vi 3개 로케일에 신규 문구가 존재한다.
- 기존 수용 기준(2026-07-01 제안: 검색/행 구성/페이지네이션)은 그대로 유지된다.

## Active SOT 충돌

- `2026-07-01-library-problems-all-view.md`의 수용 기준은 `검색 패널 + 혼합 리스트 + 페이지네이션` 구조를
  정의한다. 이 제안은 그 사이 계층(필터 카드)을 추가하는 후속 제안이며, 선행 제안의 다른 기준(통계 패널
  미노출, row 구성, 태그/저장 해제 재사용)은 변경하지 않는다.
