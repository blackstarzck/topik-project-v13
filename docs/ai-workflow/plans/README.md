# AI Workflow Plans

Save larger plans in this folder using `YYYYMMDD-HHMM-task-slug.md`.

Each plan should follow the relevant sections from `../report-template.md`, especially:

- User goal and accepted scope.
- Context ledger path when required.
- Docs consulted and extracted requirements.
- Test strategy.
- Agent assignments, if any.
- Verification plan.
- Known risks and approval gates.
