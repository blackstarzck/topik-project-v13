Writing API v13 Screen Map

Last synced: 2026-06-23

Historical snapshot — 2026-07-07. Generated from former TALKPIK external API documentation. The original service and documentation routes are no longer available.

Submit Contract

The captured contract does not accept task_id. It specifies task_type and text, with question_id only when the problem came from the external writing task list.

{
  "task_type": "Q54",
  "question_id": "topik-writing-54-0001",
  "text": "student answer...",
  "user_id": "112a6b57-9564-4990-8bf3-6b536d622008"
}

task_type is one of Q51, Q52, Q53, or Q54. question_id, user_id, lang, and passage_context are optional in the captured schema.

Evaluation Lookup

The captured schema registers GET /api/evaluation/{submission_id} and GET /api/evaluation/{submission_id}/feedback.

Flow

  1. The learner writes a TOPIK 51-54 answer.
  2. The v13 server action creates or updates the local submission row and calls POST /api/writing/submit.
  3. The external API returns HTTP 202 with submission_id and a processing status.
  4. The app polls GET /api/evaluation/{submission_id} until status is graded.
  5. The app fetches GET /api/evaluation/{submission_id}/feedback and syncs feedback into the local database.
