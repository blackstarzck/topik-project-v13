Submit Contract

The v13 app sends the external writing submission payload according to the Swagger endpoint request example.

{
  "task_type": "Q51",
  "task_id": "Q51",
  "text": "student answer...",
  "user_id": "current"
}

task_id is not the local Supabase problem_id UUID. It is the external TOPIK task code: Q51, Q52, Q53, or Q54.

OpenAPI Gap

POST /api/writing/submit tells clients to poll GET /api/evaluation/{submission_id}, but the current live /openapi.json does not register any /api/evaluation/... path. Keep this mismatch visible when changing the feedback flow.

Flow

  1. The learner writes a TOPIK 51-54 answer.
  2. The v13 server action creates or updates the local submission row and calls POST /api/writing/submit.
  3. The external API returns HTTP 202 with submission_id and status: processing.
  4. The app polls for grading, then syncs feedback into the local database when graded.
  5. The feedback screen displays score, summary, sentence-level corrections, and next actions.
