# Wireframe AI Concept Prompt Standards

Every concept prompt must include these shared constraints.

## Framing

- Desktop 1280x900 web app screenshot.
- Edge-to-edge app UI only.
- No browser address bar, tabs, bookmarks bar, OS window title bar, device frame, or watermark.
- The source screenshot is a reference for layout, state, and information architecture, not a pixel edit target.

## Visual System

- Follow `DESIGN.md`: Mist `#f4f4f5`, Snow `#ffffff`, Fog `#ececee`, Ink/Obsidian text, Obsidian `#09090b` primary CTA only.
- Use Cosmica-like single sans typography, compact density, weight-driven hierarchy, no letter spacing.
- Use Ant Design-friendly structure and recognizable component affordances.
- Korean UI text is visual direction only and not the final copy source.

## Screen Type Rules

- `workspace`: restrained 4-8px panel radii, dense scan-friendly information, one clear primary action per task area.
- `auth`: calm central or split auth form, no raw provider/token/session internals, recovery routes visible.
- `modal`: dimmed original context, centered modal, one clear primary decision, background inactive.
- `public_landing`: product signal in first viewport, inspectable product previews, larger marketing radii allowed when not used as app workspace panels.
- `legal`: document-first reading surface, no marketing hero, no invented legal finality or support channel.

## Negative Constraints

- No loud AI gradients, purple/blue glow, decorative orbs, chromatic CTA repetition, card drop-shadow stacks, raw debug text, exposed tokens, or provider error details.
