# 2026-06-17 AI Deferred and MVP Scope Decision

이 문서는 2026-06-17 코드베이스 조사 결과와 사용자 결정을 기록한 프로젝트 스코프 결정 문서다. `docs/Wireframe/`, `docs/flow/`, `docs/development-core-planning/` 사이에 스코프 판단이 갈릴 때, 아래 범위에서는 이 문서를 우선 기준으로 삼는다.

## 결정 요약

- 실제 AI 첨삭, 실제 AI 분석 처리, AI 사용량 한도, 작성 중 AI 대화 피드백은 잠시 보류한다.
- 위 AI 관련 기능을 사용자 화면에 노출해야 할 때는 "개발중", "출시 예정", "준비중"처럼 아직 완성되지 않았음을 명확히 안내한다.
- 결제/구독 provider, 외부 알림/채널 연동, 정식 법무 문서처럼 기존 조사 6번에 해당하는 외부 연동·운영 확정 항목도 같은 방식으로 보류한다.
- 6월 22일 MVP 문서에서 제외된 `profile` 편집과 비밀번호 재설정 화면은 개발해도 무방하다.
- "6/22 MVP" 기준으로 작업할 때는 MVP 제외 또는 보류 기능을 숨기거나 후속/준비중으로 표시한다.
- "전체 Wireframe" 기준으로 작업할 때는 stub, placeholder, deferred로 남은 영역을 실구현 대상으로 본다.

## 보류 대상

아래 항목은 route나 UI 껍데기가 존재하더라도 완료 기능으로 말하지 않는다.

| 영역 | 현재 판단 | 사용자 안내 원칙 |
| --- | --- | --- |
| 실제 LLM 기반 AI 첨삭/채점 | 보류 | mock 결과를 실제 AI 결과처럼 표현하지 않는다. 필요한 경우 "AI 첨삭 기능 준비중"으로 안내한다. |
| D-M2 실제 AI 분석 파이프라인 | 보류 | 로딩/분석 상태 UI가 있더라도 실제 비동기 분석 완료를 보장하는 것처럼 안내하지 않는다. |
| AI 첨삭 사용량 한도 | 보류 | 일/월 한도 강제가 아직 없으면 잔여 횟수나 차감 완료처럼 표시하지 않는다. |
| 작성 중 AI 대화 피드백 최대 3턴 | 보류 | 작성 화면에서는 개발중/출시 예정 기능으로만 표시한다. |
| 결제/구독 provider 연동 | 보류 | 결제 성공, 구독 변경, 결제수단 변경, 구독 취소가 실제 처리된 것처럼 말하지 않는다. |
| 외부 알림/채널 연동 | 보류 | Zalo, 운영 이메일, 외부 리마인더는 실제 발송 가능 상태가 검증되기 전까지 준비중으로 표시한다. |
| 정식 약관/개인정보 처리방침 | 보류 | placeholder는 법무 검토 전 임시 문구임을 숨기지 않는다. |

## MVP 기준과 전체 Wireframe 기준

작업 요청이나 문서에서 기준이 명확하지 않으면 먼저 어떤 기준을 쓰는지 판단한다.

### 6/22 MVP 기준

- 핵심 학습 루프를 우선한다.
- MVP 제외 기능은 화면에 노출하지 않거나, 노출이 필요하면 후속/준비중 상태로 표시한다.
- 결제, 구독, 외부 알림, 고급 AI 기능은 실제 완료 기능으로 취급하지 않는다.
- 프로필 편집과 비밀번호 재설정 화면은 MVP 제외 항목이었지만 개발해도 무방하다.

### 전체 Wireframe 기준

- `docs/Wireframe/`와 `docs/flow/`에 존재하는 사용자 앱 화면은 구현 대상으로 본다.
- 현재 코드의 `stub`, `placeholder`, `deferred`는 그대로 방치할 상태가 아니라 실구현 backlog로 본다.
- 다만 AI와 외부 연동 항목은 이 문서의 보류 결정을 우선 적용한다.

## 구현 지침

- 보류 기능은 사용자에게 기능이 완성된 것처럼 보이게 만들지 않는다.
- 준비중 안내를 넣을 때는 사용자가 다음 행동을 이해할 수 있게 한다. 예: 작성은 계속 가능하지만 AI 대화 피드백은 출시 예정이라고 표시한다.
- mock, stub, placeholder를 유지하는 경우 코드 주석과 사용자 문구가 서로 모순되지 않게 한다.
- 실제 provider, 실제 LLM, 실제 quota enforcement를 붙이는 작업은 별도 스코프 결정 또는 명시 요청이 있을 때만 진행한다.

## 결정 근거

- 2026-06-17 코드베이스 조사에서 route와 화면 뼈대는 대체로 존재하지만, AI/외부 연동 핵심 동작은 mock, stub, deferred 상태로 확인되었다.
- 사용자는 AI 관련 조사 항목 1~4와 외부 연동·운영 확정에 해당하는 조사 항목 6을 잠시 보류하기로 결정했다.
- 사용자는 프로필 편집과 비밀번호 재설정 화면은 6/22 MVP 제외 항목이어도 개발 가능하다고 결정했다.
- 사용자는 6/22 MVP 기준과 전체 Wireframe 기준을 구분해 적용하는 방향을 승인했다.
