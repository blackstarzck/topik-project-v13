빨강

바로 고칠 것

피드백 직접 열기와 모바일 구독 화면에서 실패가 확인됐습니다. 회원가입 전환은 테스트 기준 갱신 문제이고, 알림은 부분 구현과 보류 범위를 나눠 봐야 합니다.

노랑

주의할 것

전체 화면 테스트는 한 번에 끝나지 않아 화면 크기와 기능별로 나누어 확인했습니다.

초록

통과한 것

코드 문법, 연결 상태, 일반 기능 테스트는 통과했습니다. 핵심 글쓰기 흐름도 확인했습니다.

한 줄 결론

지금 상태는 조건부 통과입니다. 앱 전체가 완전히 멈추지는 않지만, 사용자가 결과를 직접 다시 열거나 모바일에서 구독 화면을 볼 때 막힐 수 있습니다. 알림은 완성 기능이 아니라 부분 구현 상태로 따로 봐야 합니다.

사용자가 실제로 겪을 수 있는 문제

정정

회원가입 화면 전환은 새 디자인 기준 확인 필요

최근 회원가입 화면은 처음에 이름만 보여주고, 입력이 끝날 때마다 다음 칸을 하나씩 보여주는 방식으로 바뀌었습니다. 기존 테스트는 예전처럼 비밀번호 확인 칸이 바로 보여야 한다고 기대하고 있었습니다.

정리: 현재 증거만으로는 제품 결함이 아니라, 테스트가 새 화면 방식을 따라가지 못한 문제로 보는 것이 맞습니다.

P1

피드백 링크 직접 열기 문제

사용자가 이전 첨삭 결과 링크를 직접 열 때, 데스크톱에서 피드백 화면 대신 찾을 수 없는 화면으로 떨어지는 경우가 확인됐습니다.

영향: 저장된 학습 결과를 다시 확인하지 못할 수 있습니다.

부분 구현

알림은 아직 완성 기능이 아닙니다

알림 설정 화면과 일부 저장, 인앱 알림 쪽은 구현되어 있습니다. 하지만 실제 이메일, Zalo, push 발송은 프로젝트 문서상 아직 보류입니다.

정리: 알림 전체를 출시 완료 기능처럼 보면 안 됩니다. 현재는 설정/인앱 일부만 확인 대상이고, 외부 발송은 후속 개발 범위입니다.

P1/P2

모바일 구독 화면 문제

모바일에서 구독 화면을 열 때 서버 오류나 화면 초기화 오류가 기록됐습니다. 데스크톱은 통과했고 태블릿은 다시 실행했을 때 통과했습니다.

영향: 모바일 사용자가 구독 상태를 보려고 할 때 화면이 불안정할 수 있습니다.

확인한 흐름

이번 QA는 단순히 화면이 뜨는지만 본 것이 아니라, 사용자가 움직이는 순서까지 확인했습니다.

검사 결과 쉬운 설명
기본 코드 검사 통과 코드 문법과 연결 상태를 확인했고 새 오류는 없었습니다. 경고는 6개 남았습니다.
자동 기능 테스트 통과 작은 기능 단위 테스트는 761개 통과했고 3개는 의도적으로 건너뛰었습니다.
보안/패키지 점검 실패 사용 중인 개발 도구와 관련 패키지에서 5개 보안 알림이 나왔습니다.
화면 자동 테스트 나누어 확인 전체를 한 번에 돌리면 제한 시간 안에 끝나지 않아 화면 크기별로 나누어 확인했습니다.
알림 실패 상태 부분 확인 알림 설정/인앱 일부는 구현되어 있지만, 외부 발송은 보류입니다. 실패 상태 테스트는 현재 구현 범위에 맞게 다시 정리해야 합니다.

시나리오별 상태

범위 상태 쉽게 풀어쓴 설명
공개 화면과 약관 통과 첫 화면, 약관, 개인정보 화면은 데스크톱과 모바일에서 기본 확인을 마쳤습니다.
회원가입/로그인 테스트 갱신 필요 회원가입 화면이 단계형으로 바뀌었는데, 일부 테스트가 예전 화면 구조를 기대하고 있었습니다.
비밀번호 재설정 주의 잘못된 링크로 들어와도 먼저 새 비밀번호 입력 화면이 보입니다. 실패 안내가 늦게 나옵니다.
이메일 인증 주의 잘못된 이메일 주소가 들어와도 인증 메일을 보낸 것처럼 보입니다.
학습 홈과 문제 목록 통과 대시보드, 추천, 문제 목록, 쓰기 화면 기본 렌더링은 확인했습니다.
쓰기와 제출 통과 답안 작성, 제출 확인, 분석 중 화면, 핵심 글쓰기 흐름을 확인했습니다.
피드백/비교 리포트 실패 일부 피드백 화면 자체는 통과했지만, 특정 피드백 주소를 직접 열 때 데스크톱에서 실패했습니다.
내 서재/PDF 통과 최근 재검사에서는 내 서재와 PDF 내보내기 모달이 통과했습니다.
알림 설정 부분 구현/보류 설정 화면과 인앱 알림 일부는 구현되어 있습니다. 실제 이메일, Zalo, push 발송은 아직 보류 범위입니다.
구독/결제 안내 실패 일부 결제 기능 자체는 보류 상태로 보이지만, 모바일 구독 화면에서 오류가 기록됐습니다.

우선 처리 순서

  1. 피드백 링크 직접 열기 문제를 확인합니다. 학습 결과를 다시 보는 핵심 흐름입니다.
  2. 알림은 구현된 범위와 보류 범위를 나눠 다시 테스트합니다. 외부 발송은 완료 기능으로 보지 않습니다.
  3. 모바일 구독 화면 오류를 확인합니다. 모바일에서만 흔들리는지, 서버 오류인지 분리해야 합니다.
  4. 회원가입 전환 테스트를 새 단계형 화면에 맞게 고칩니다. 제품 결함으로 단정하지 않습니다.
  5. 보안 알림이 난 패키지를 별도 작업으로 정리합니다. 의존성 변경은 범위가 커질 수 있습니다.

이번에 하지 않은 일

  • 소스 코드는 수정하지 않았습니다.
  • 테스트 파일도 수정하지 않았습니다.
  • 커밋이나 배포는 하지 않았습니다.
  • 실제 결제 기능이나 실제 AI 채점 품질은 이번 QA 범위가 아니었습니다.
