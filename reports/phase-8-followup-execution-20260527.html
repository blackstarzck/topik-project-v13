📖 용어집

Codex GPT-5
OpenAI Codex CLI — read-only 샌드박스로 코드 평가하는 다른 AI. 본 작업에서 7 라운드 검수에 활용.
verifyOtp / exchangeCodeForSession
Supabase Auth API. 이메일 링크는 verifyOtp, OAuth는 exchangeCodeForSession. 둘 다 callback에서 호출.
Set-Cookie 헤더
HTTP 응답에 포함되어 브라우저가 cookie 저장하게 하는 헤더. 이게 없으면 verifyOtp는 DB에서 성공해도 사용자 브라우저는 인증된 상태 안 됨.
Server Component vs Route Handler
Next.js 13+의 두 가지 server-side 실행 환경. Server Component는 React 트리 렌더링 전용 — cookies() read-only. Route Handler는 HTTP 응답 직접 emit — cookies().set이 응답 헤더에 실제 emit됨.
RFC 7231 fragment retain
HTTP redirect 시 Location 헤더에 fragment 없으면 브라우저가 원래 URL의 #fragment를 새 location에 자동 보존. Phase 8.5 fragment fallback이 이 spec을 활용.
pg_cron
PostgreSQL 안에서 정해진 시각에 SQL을 자동 실행하는 extension. Supabase Cloud에 일반적으로 활성화. cron.job 테이블에 등록된 job 조회 가능.
admin/generate_link
Supabase Auth admin API. service_role key로만 호출 가능. 이메일 발송 없이 직접 magic link URL + hashed_token 받을 수 있어 메일 한도 우회용으로 유용.
service_role key
