고치는 법? 별도 구현 요청에서 "문서와 현재 소스를 함께 대조한다"는 문구로 바꿉니다.

이번 주 안에: Node 버전 맞추기

무슨 일? 로컬 package.json은 Node >=24 <25를 요구하지만, GitHub Actions는 Node 22를 씁니다.

왜 문제? 지금 검증기는 통과하지만, CI와 로컬 기준 런타임이 달라서 나중에 검사 확장 시 결과가 갈릴 수 있습니다.

고치는 법? CI를 Node 24로 올리거나, workflow checker만 Node 22에서 돌리는 이유를 문서화합니다.

여유 있을 때: 자동검사 범위 보강

무슨 일? 현재 workflow checker는 stale project-state 문구나 Claude permission allowlist 위험을 직접 잡지 않습니다.

왜 문제? 이번 감사 같은 수동 점검이 없으면 같은 종류의 운영 결함이 다시 들어올 수 있습니다.

고치는 법? 별도 작업으로 "src/package 존재 + 아직 코드 안 짰음 문구"와 위험 명령 allowlist를 감지하는 검사를 추가합니다.
