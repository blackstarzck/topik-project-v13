⑦ 용어집

Route Handler
Next.js App Router 에서 HTTP 메서드 단위로 응답하는 서버 함수 (route.ts). page.tsx 와 달리 HTML 을 렌더하지 않고 NextResponse 를 반환. cookies().set() 호출이 응답 헤더에 실제로 emit 된다는 점이 server component 와의 결정적 차이.
PKCE
Proof Key for Code Exchange. OAuth 표준의 보안 강화 확장. 브라우저가 만든 secret 을 서버가 verify 하는 방식으로 "코드 가로채기" 방어. Supabase 가 기본으로 사용.
verifyOtp / exchangeCodeForSession
Supabase 가 메일 링크 / OAuth code 를 세션 쿠키로 교환하는 server API. 성공하면 sb-*-auth-token 쿠키 set.
silent fail (cookie set)
@supabase/ssr 의 createServerClient 가 server component 에서 호출되면 cookies().set() 이 예외만 안 던지고 실제로는 응답 헤더에 안 박힘. 그래서 page.tsx 콜백은 "verifyOtp 는 성공했는데 다음 페이지에선 미인증" 으로 보임. P0 fix 의 근본 원인.
fragment fallback
옛 implicit flow 메일 링크는 토큰을 URL #fragment 에 박아 보냄. 서버는 fragment 를 읽을 수 없어 별도 client component 가 window.location.hash 를 파싱해 setSession 호출.
pg_cron
Postgres extension. cron.schedule(jobname, schedule, command) 로 SQL 자동 실행. 본 프로젝트는 매일 04:00 UTC 에 cleanup_unconfirmed_users 실행.
RLS (Row Level Security)
Postgres 의 행 단위 권한 정책. 본 프로젝트는 auth.uid() 기반으로 자기 데이터만 보이게 강제. SECURITY DEFINER 함수는 RLS bypass 가능.
cross-audit
다른 모델 (Codex GPT-5.5) 에게 독립적으로 검증받기. 자기 평가는 confirmation bias 에 약하다는 직접 교훈 (2026-05-27 memory).
