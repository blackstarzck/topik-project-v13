51~54번 쓰기 화면, 전체 흐름은 잘 만들어졌습니다.
다만 먼저 정할 일 4가지와 고칠 문제 4가지가 있어요.

문제를 풀고 → AI가 분석하고 → 피드백을 보고 → 다음 문제로 이어지는 큰 흐름은 코드에서 끝까지 정상으로 이어집니다. 핵심 기능과 보안도 대체로 양호합니다.

검수 대상: 51·52·53·54번 작성 화면 + 제출 확인창 · AI 분석 화면 · 자동저장 경고창  |  방식: 설계 문서와 실제 코드를 한 줄씩 대조 (읽기 전용, 고치지 않음)

큰 그림: 학습 흐름은 이렇게 이어집니다

답안 작성→ 제출 확인→ AI 분석→ 피드백 확인→ 다음 문제 비교 리포트 PDF 저장

이 순서대로 화면이 실제로 연결되는 것을 확인했습니다. 제출에 성공하면 분석 화면으로 바뀌고, 분석이 끝나면 자동으로 피드백 화면으로 넘어갑니다.

🟡 먼저 정해야 할 4가지

1문제 푸는 화면에서 왼쪽 메뉴가 통째로 사라져요 4개 화면 모두

무슨 일
51~54번을 풀 때, 다른 학습 화면으로 가는 왼쪽 메뉴가 안 보입니다. 모바일에서도 메뉴 버튼이 없습니다.
설계 문서
“이 화면들에서도 메뉴는 보여야 한다”라고 정해져 있습니다. 대신 “저장 안 된 답안이 있으면, 메뉴를 눌러도 바로 안 나가고 먼저 물어본다”가 규칙입니다.
지금 상태
메뉴를 아예 숨겨 시험처럼 집중하게 만든 것으로 보입니다. 그런데 이렇게 바꾸기로 한 결정 기록(문서)이 없습니다.
정할 것 → ⓐ ‘시험 집중 모드(메뉴 숨김)’를 공식 규칙으로 인정할지, 아니면 ⓑ 문서대로 ‘메뉴는 보이되 나갈 때 물어보기’로 되돌릴지.

253번 ‘참고 자료를 없애라’는 지시와 ‘그래프는 꼭 필요’가 충돌해요

53번은 그래프(도표)를 보고 그 내용을 글로 설명하는 문제입니다. 그래프가 없으면 문제가 성립하지 않습니다.

새 지시문“51~54 화면에서 참고 자료를 없애라”
원래 화면 문서(53번)“그래프, 조건, 참고 자료를 왼쪽에 보여줘라”
지금 코드그래프 카드 + 참고 자료 카드를 둘 다 보여줌
헷갈리는 점 → ‘참고 자료를 없애라’가 ⓐ 보조 설명 카드만 없애라(그래프는 유지)인지, ⓑ 그래프까지 다 없애라(그러면 53번이 깨짐)인지 불분명합니다. 53번에서 무엇을 남길지 정해야 합니다.

3제출 직전 확인창에 보여야 할 내용이 빠졌어요

구분설계 문서가 요구한 것지금 확인창
답안 요약문제 유형·답안 길이·저장 시각없음
분석 안내“제출하면 AI가 분석을 시작하고 잠시 기다립니다”없음
버튼 모양취소·제출 버튼 같은 너비제출이 더 넓음

필요한 안내 문구는 이미 만들어져 있는데 화면에서 쓰지 않고 있습니다. 또 테스트에는 “이건 일부러 뺀 것”이라고 적혀 있지만, 그렇게 정한 문서가 없습니다.

정할 것 → ⓐ 지금의 간단한 확인창을 공식으로 인정할지, ⓑ 문서대로 요약·안내·버튼 모양을 다시 넣을지.

4문서가 옛날 방식으로 적혀 있어요 코드는 최신

바뀐 점
채점을 ‘앱 안에서 한 번에 처리’ → ‘외부 채점 서비스에 보내고 결과를 받아오기’로 바꿨습니다.
코드
최신(외부 채점) 방식이 맞게 되어 있습니다.
문제
일부 설계 문서가 아직 옛 방식으로 적혀 있어, 검수 때 “문서와 다르다”로 잡힙니다.
정할 것 → 코드 문제가 아닙니다. 옛 문서 문구만 최신으로 고치면 됩니다.

🔴 사용자가 겪을 수 있는 실제 문제 4가지

문제무슨 일인가상태
영어 오류 메시지 노출 외부 채점으로 보낸 뒤 그 문제를 더 풀 수 없을 때, 친절한 한국어 안내 대신 영어 섞인 기술 메시지가 사용자에게 보일 수 있습니다. 실제로 닿을 수 있는 경로입니다. 바로 처리
51·52번 ‘AI 총평’이 안 보임 AI가 매긴 전체 총평이 53·54번 피드백에는 보이는데 51·52번 피드백에는 안 보입니다. 총평은 잘 저장되고 있어, 화면에 표시만 추가하면 됩니다. 주의
분석 중 이탈 경고 없음 AI 분석 중 브라우저 뒤로가기·새로고침을 하면 “분석이 중단됩니다” 경고 없이 화면이 사라집니다. 화면 안 ‘나가기’ 버튼은 경고가 뜨지만 브라우저 버튼은 못 막습니다. 주의
중복 제출 빈틈 화면에서는 중복 제출을 막습니다. 다만 인터넷이 끊겼다 다시 시도하거나 탭을 두 개 열면 같은 답이 두 번 들어갈 수 있는 구조적 틈이 있습니다. 주의

이 밖에 ‘지문은 3줄까지, 도움말은 2줄까지’ 같은 세밀한 표시 규칙은 코드로 강제하지 않습니다(눈으로 확인 필요). 자동저장 경고창은 설계 문서 자체가 모호한 부분이 있어 별도 정리가 필요합니다.

  • 전체 학습 흐름 — 제출 → 분석 → 피드백 → 다음 문제·비교 리포트·PDF가 끝까지 이어집니다.
  • 54번 작성 안내 — 문제별 ‘글의 구조 제안’을 보여주는 새 방식으로 잘 바뀌었습니다.
  • AI 분석 화면 — 새 방식(페이지 전환)대로 동작하고, 뒤로가기로 잘못 되돌아오지 않습니다.
  • 외부 채점 연결 — 비밀 키가 노출되지 않고, 본인 답안만 조회하도록 안전하게 처리됩니다.
  • 로그인·보안 — 로그인한 본인만 자기 답안을 보고 제출하도록 막는 규칙이 작동합니다.
